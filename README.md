# 🎙️ Audio Recognition with Python

A simple project to explore **audio recognition** using **Python**, the `speech_recognition` library, and `pyttsx3`.  
The program listens through your microphone, recognizes spoken words using Google's speech recognition engine, and prints the text in the terminal.

Say `quit` to exit the application.

---

## 🧠 What This Project Demonstrates

- Real-time audio input from a microphone 🎤  
- Speech-to-text conversion using `speech_recognition`  
- Graceful handling of audio errors and unrecognized speech  
- Basic voice command detection (e.g., `"quit"`)

---

## 🚀 Technologies Used

- Python 3.x 🐍  
- [speech_recognition](https://pypi.org/project/SpeechRecognition/)  
- [pyttsx3](https://pypi.org/project/pyttsx3/) *(optional, used for text-to-speech in more advanced versions)*
